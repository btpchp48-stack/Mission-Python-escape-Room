# MISSION PYTHON: The Cute Escape Room

เกม Escape Room ฝึกทักษะภาษา Python ผ่าน Google Colab

## Project Description
ผู้เล่นติดอยู่ในห้องทดลอง AI ที่ระบบรักษาความปลอดภัยขัดข้อง ต้องตอบคำถามเกี่ยวกับภาษา Python ให้ผ่านครบ 5 ห้อง เพื่อรวบรวม Digital Keys และหนีออกจากห้องทดลอง

## Game Rooms
1. The Gate of Conditions — if / elif / else
2. The Loop Chamber — for / while / range
3. The Function Lab — def / parameters / return
4. The Debugging Room — Errors / break
5. The Final Challenge — Python Review

## Game Rules
- มีทั้งหมด 5 ห้อง ห้องละ 2 คำถาม
- ตอบถูกได้รับ 10 คะแนน
- ใช้คำใบ้ได้ 1 ครั้งต่อห้อง หัก 2 คะแนน
- มีเวลา 3 นาทีต่อห้อง
- ตอบถูกครบ 2 ข้อเพื่อปลดล็อกห้องถัดไป

## How to Run
1. Download the `.ipynb` file.
2. Open Google Colab.
3. Select File > Upload notebook.
4. Run the code cell.
5. Click Start Mission and answer the questions.
